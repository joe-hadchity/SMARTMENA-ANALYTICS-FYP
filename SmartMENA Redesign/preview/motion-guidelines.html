Do / Don't
✓ Do
Use 150ms for hover/focus micro-interactions. Fast enough to feel responsive.
✕ Don't
Never use bounce or spring easing on data tables or financial figures — it undermines trust.
✓ Do
Animate opacity + translate together for entering elements (fade-up pattern).
✕ Don't
Don't animate layout properties (width, height, padding) — use max-height or transform instead.
✓ Do
Use exit animations (250ms, ease-exit) to help users understand where elements went.
✕ Don't
Never use gradient animations, shimmer effects, or pulsing on data-dense screens.
